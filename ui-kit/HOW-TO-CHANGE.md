# Шпаргалка: як швидко щось змінити (для захисту)

Запуск (один раз, у папці `ui-kit`):

```bash
npm install
npm run storybook
```

Відкрий `http://localhost:6006`. Тепер **змінюєш файл → зберігаєш (Ctrl+S) → сторінка оновлюється сама**, перезапускати нічого не треба.

## Де що лежить

| Що змінити | Файл | Що шукати |
|---|---|---|
| Кольори, шрифти, відступи, радіуси | `src/styles/tokens.css` | змінні `--color-…`, `--font-…`, `--space-…`, `--radius-…` |
| Вигляд кнопки (форма, розмір, стани) | `src/components/components.css` | блок `/* ---------- Button ---------- */`, клас `.cs-btn` |
| Вигляд поля вводу / картки / навігації | `src/components/components.css` | блоки Field, Card, NavBar |
| Текст на кнопці чи екрані | `src/screens/Today.jsx`, `Chat.jsx` та ін. | сам текст у лапках |

## Типові прохання викладача

| Прохання | Що зробити |
|---|---|
| «Заміни синій колір на зелений» | У `tokens.css` у блоці `:root` знайти `--color-primary: var(--navy-900);` і написати `var(--green-800)`. Для hover і active змінити два рядки нижче так само. Або в Storybook у тулбарі Theme обрати «Forest». |
| «Зроби кнопки більш круглими» | У `tokens.css` змінити `--radius-sm: 8px;` на `--radius-sm: 999px;` |
| «Збільш шрифт заголовків» | У `tokens.css` змінити `--fs-h1`, `--fs-h2` або `--fs-h3` |
| «Інший шрифт» | У `tokens.css` змінити `--font-heading` або `--font-body` (шрифт має бути підключений у `index.html`) |
| «Більші відступи» | У `tokens.css` збільшити значення `--space-3`, `--space-4`, `--space-5` |
| «Золотий акцент → інший колір» | У `tokens.css` змінити `--color-accent` (і `--color-accent-strong`, `--color-accent-soft`) |
| «Нова кнопка іншого кольору» | У `components.css` скопіювати блок `.cs-btn--secondary`, перейменувати на `.cs-btn--мій`, поставити свої `--btn-bg…`; у `Button.stories.jsx` додати назву в список `variants` |
| «Інший колір помилки / успіху» | У `tokens.css` змінити `--color-error` або `--color-success` |

## Якщо щось зламалось

Поверни файл у попередній стан командою `git checkout -- шлях/до/файлу` або натисни Ctrl+Z у редакторі.
